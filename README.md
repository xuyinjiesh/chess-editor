# Chess Studio · 棋局工坊

在浏览器里设计、试玩和分享棋类游戏。从经典模板开始，自定义棋盘、棋子与规则，也可以让 AI 把想法变成可以试玩的作品。

## 可以做什么

| 功能 | 用法 |
| --- | --- |
| 设计棋盘 | 调整 3–24 行列，选择方格、交叉网格、格内网格、象棋或六边形布局；蜂巢棋盘支持交错矩形与菱形 |
| 自定义棋子 | 创建棋子类型，修改双方符号与外观，点击或拖拽摆放 |
| 标记区域 | 绘制带颜色和标签的区域，供自定义规则使用 |
| 自由编写规则 | 用 JavaScript 定义走法、回合和胜负，支持规则试运行 |
| 手牌与储备区 | 规则可定义双方手牌、备用棋子及公共区域，支持选择、数量、翻转和手机布局 |
| 本地人机对弈 | 内置棋类与自定义规则，三档难度、先后手、暂停、悔棋及电脑自我对弈 |
| AI 辅助设计 | 描述想法，生成棋盘、棋子、区域、规则和界面设置，预览后应用 |
| 保存与分享 | 浏览器自动保存、本地作品库、JSON 导入和导出 |
| 静态作品广场 | 搜索作品、查看玩法、独立试玩与 AI 对弈、固定版本分享、下载与复制改编 |
| 联机对弈 | 创建房间，分享房间码或链接，邀请朋友加入或观战 |
| 调整观感 | 8 套棋盘主题、自定义配色、夜间模式、翻转、缩放和走子动效 |

内置 **国际象棋、中国象棋、五子棋、黑白棋和井字棋**。每个模板都可以直接试玩，也可以作为新棋类的起点。

## 快速开始

打开[在线体验](https://xuyinjiesh.github.io/chess-studio/)，无需安装。

1. 在左侧选择一个经典模板，或新建项目。
2. 用上方的「棋盘」「棋子」「区域」「规则」「界面」调整设计。
3. 点击「开始试玩」进行本机双人操作，或点击「人机对弈」选择电脑对手。
4. 点击「保存作品」保存在当前浏览器，或「导出」为 JSON 文件。

试玩时点击「放大棋盘」或按 `G` 可以隐藏侧栏；按 `Esc` 返回，棋局会保留。

选中或拖起棋子、落子和吃子会播放不同力度的玉石碰撞实录音效。点击棋盘下方工具栏的扬声器可开关音效；设置在编辑器与作品广场间共用，刷新后仍然保留。

## 用 AI 设计棋类

在右侧打开 **AI 助手 → 配置模型**，填写兼容 Chat Completions 的 API 地址、模型名称和 API Key，然后描述你的想法。例如：

> 设计一个 8×8 的双人棋。双方各有三名守卫和一名国王；守卫每次横向或纵向移动一格，进入中央区域可以额外行动一次，吃掉对方国王获胜。

AI 会生成完整设计，包括可执行的规则代码。**先查看预览，再点击「应用这个设计」**；也可以继续手动修改。

- 使用你自己的模型服务；项目没有内置 API Key，服务商可能收费。
- 模型接口需要允许浏览器跨域访问（CORS）。
- API Key 只保留在当前页面内存中，刷新后清除；当前项目与描述会发送给你配置的模型服务。
- AI 可以调整名称、简介、强调色和提示等界面设置；目前不支持运行 AI 生成的任意 HTML 页面。

## 和电脑对弈

点击顶栏 **人机对弈**，选择阵营和难度，然后开始新对局。引擎在本机浏览器运行，不需要模型接口或 API Key，也可选择观看电脑自我对弈。原来的「开始试玩」仍用于本机双人操作。

内置五种棋类均可使用。自定义棋类支持双人、完全信息、确定性的回合制规则，包括额外回合；AI 助手会同时生成合法走法和局面评价函数。已有设计可在 AI 助手中选择「保持当前玩法，为人机对弈补齐 getLegalMoves 和 evaluate」，预览后应用。旧规则也可尝试兼容搜索，复杂规则建议补齐接口。

电脑可暂停或重试；人机悔棋会撤回自己的走子及电脑的回应。具体规则接口、适用范围与限制见[本地 AI 说明](docs/LOCAL_AI.md)。

## 本地运行

需要安装 Node.js 22.6 或更新版本，建议使用较新的 **Node.js 22** 或 **Node.js 24**。

```sh
git clone https://github.com/xuyinjiesh/chess-studio.git
cd chess-studio
npm ci
npm run dev
```

打开终端显示的地址，默认是 `http://localhost:5173`。

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动开发服务器 |
| `npm test` | 运行自动测试 |
| `npm run build` | 检查作品广场、检查类型并构建生产文件 |
| `npm run preview` | 本地预览构建结果 |
| `npm run server` | 启动可选的 WebSocket 中继 |
| `npm run gallery:check` | 检查广场清单、作品文件与封面 |

## 发布自己的作品

作品广场无需后端，发布权限来自 Git 仓库的写入权限。访客可以试玩、下载和改编；页面上的「发布」只导出发布包，不会直接上传网站。

1. 在编辑器完成设计，检查双人操作与人机对弈。
2. 点击「发布」，填写作品信息并导出 `.qijing-release.json` 发布包。
3. 在项目目录导入发布包并预览：

   ```sh
   npm run gallery:add -- "你的作品-v1.qijing-release.json"
   npm run build
   npm run preview
   ```

4. 确认后提交生成的 `public/gallery/` 文件并推送到 `main`，随网站一起部署。

更新作品时增加版本号，旧分享链接继续有效。发布格式、来源署名与完整流程见[静态作品广场说明](docs/STATIC_GALLERY.md)。

## 和朋友联机

打开顶栏「联机房间」，填写昵称，用当前项目创建房间，再分享房间码或邀请链接。

| 方式 | 适用场景 |
| --- | --- |
| 房主托管 | 默认方式，由房主浏览器处理规则，通过 WebRTC 同步对局 |
| 指定服务器 | 使用自己部署的 WebSocket 中继，适合需要统一服务器地址的场景 |

房主执白方（中国象棋为红方），第一位加入者执黑方，其他人观战；每个房间最多 8 人。**房主需要保持页面打开**。连接受网络环境影响，必要时可配置 TURN 或使用指定服务器。

自建中继可以运行 `npm run server`。服务器地址、TLS 和信令配置见[联机部署说明](docs/DEVELOPMENT.md#联机部署)。

## 常用快捷键

Windows / Linux 使用 `Ctrl`，macOS 使用 `⌘`。

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl / ⌘ S` | 保存作品 |
| `Ctrl / ⌘ Shift S` / `Ctrl / ⌘ O` | 导出 / 导入 |
| `Ctrl / ⌘ Z` / `Ctrl / ⌘ Shift Z` / `Ctrl / ⌘ Y` | 撤销 / 重做 |
| `Space` | 切换编辑 / 试玩；焦点在普通按钮时激活按钮 |
| `V` / `P` / `E` / `R` | 选择 / 放置棋子 / 擦除 / 绘制区域 |
| `1`–`9` / `Delete` | 选择棋子类型 / 删除选中棋子 |
| `F` / `D` / `G` | 翻转棋盘 / 切换夜间模式 / 放大棋盘 |

| `Esc` / `?` | 取消选择或退出放大 / 打开使用指南 |

在输入框中编辑文字时，棋盘操作快捷键会暂停。

## 部署到 GitHub Pages

仓库包含自动部署工作流。首次部署只需：

1. 进入仓库 **Settings → Pages → Build and deployment**。
2. 将 **Source** 设为 **GitHub Actions**。
3. 将修改推送到 `main`；也可以在 **Actions → Deploy to GitHub Pages → Run workflow** 中选择 `main` 手动运行。
4. 等待工作流成功，访问 [chess-studio 在线站点](https://xuyinjiesh.github.io/chess-studio/)。

工作流会安装依赖、运行测试、按仓库名自动设置 Vite 的 `base` 并发布 `dist/`。本地验证相同子路径可运行：

```sh
npm run build -- --base=/chess-studio/
npm run preview -- --base=/chess-studio/
```

**不要直接把源码根目录作为网站发布**，否则浏览器无法加载 React / TypeScript 入口。

部署到其他静态托管平台时，运行 `npm run build` 并发布生成的 `dist/`；如果部署到子路径，构建时传入对应的 `--base=/你的路径/`。WebSocket 中继需要单独部署。

## 使用前了解

- **保存位置**：作品保存在当前浏览器中，不会自动同步到其他设备。重要设计建议导出 JSON 备份。
- **导出内容**：JSON 保存棋类设计与初始布局，不包含正在进行的对局和棋谱。
- **规则范围**：当前支持两方阵营。区域效果由自定义规则解释；六边形规则可使用通用棋盘拓扑接口。
- **中国象棋**：支持基本合法走法、将军、将死和困毙判负；尚未实现长将、长捉和自然限着等竞赛裁定。
- **联机范围**：面向朋友间对弈，暂不提供自动重连、房主迁移或竞技防作弊。
