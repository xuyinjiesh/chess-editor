## 接入内容

- `terrain.css`：象牙棋面、细双圈、楷体刻字和接触阴影。文字按 1、2、3–4、5–6、7–8 字分别使用一列、两列或三列排版，字号随棋身容器缩放。
- `BoardTerrain.tsx` / `terrain.ts`：河界、禁区、九宫与普通区域采用独立 SVG 装饰层；相邻格只绘制外围线，保留孔洞、分离区域和翻转后的逻辑位置。装饰不接收指针事件。
- 中立河石使用独立的石材轮廓和菱形标识；其他自定义文字棋子继续显示原符号。
- 编辑器、独立试玩、缩略棋盘和作品封面使用同一组棋子排版参数。小尺寸省略细纹与额外内圈。
- 保留生产棋盘的点位、尺寸计算、棋子 ID、移动动画和走棋规则。方格及六边形区域维持原有逐格标记。

- `npm test`：92 项单元测试通过，另有 1 项静态发布测试通过。
- `npm run build`：作品目录检查、TypeScript 检查及 Vite 构建通过。
- 浏览器：象棋玉石与午夜棋盘、翻转、32 子、河界及九宫；红兵 a4→a5 的提示、回合与棋谱。
- 浏览器：迷你永恒棋双方确认布阵、b1→e1 吃己方棋、放回 d1、悔棋和重做。
- 390px 手机视口：两种棋盘完整显示，无横向溢出；棋子宽高相等。
- 1 / 2 / 4 / 6 / 8 字的实际棋子均保持在棋面内；应用浏览器没有错误或警告日志。

字体使用本机楷体和宋体回退。长文字在小棋子上会缩小；未增加外部字体或位图依赖。
