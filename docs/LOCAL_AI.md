# 本地 AI 对弈

顶栏选择「人机对弈」，设置自己执哪方和电脑难度，点击「开始新的人机对局」。也可以观看电脑自我对弈。「开始试玩」仍为本机双人操作。

- 入门、标准、挑战的搜索预算分别为 250 / 900 / 2200 毫秒，另有深度和节点上限；初始化 Worker 和最终校验的时间不计入搜索预算。
- 电脑回合不能代替电脑落子。可暂停／继续电脑，或保留棋局改为双人操作。
- 人机悔棋会撤回自己的上一步及电脑的回应，包括电脑连续行动；自我对弈悔棋后会暂停。
- 重新开始、返回编辑、切换作品和连接联机房间都会取消旧搜索。人机模式与联机模式互斥。
- 引擎使用浏览器 Worker，无需模型接口或 API Key。生成设计仍使用用户配置的模型服务；网站尚未实现断网重新打开所需的离线资源缓存。

## 支持范围

支持内置国际象棋、中国象棋、五子棋、黑白棋、井字棋，以及确定性的双人完全信息自定义棋类。支持额外回合，仍使用现有规则判断胜负。随机事件、隐藏信息、同时行动和超出当前 Move 协议的动作不在这一版范围内。

搜索使用迭代加深的 Alpha–Beta 算法，按当前实际行动方选择最大／最小值。内置棋类提供棋子价值、位置或连线评价；较大连珠棋盘优先搜索已有棋子两格以内的落点。自定义规则可以提供自己的评价。它是用于试玩和设计验证的基础对手，不保证大师棋力或任意规则下的最优解。

## 自定义规则接口

这些函数都写在已有 `rules.code` 中，跟随作品保存、导入和导出，不增加 JSON 必填字段。

```js
function onMove(state, move, project) {
  // 与原规则协议相同。拒绝走法返回 { valid: false }。
  // 合法走法返回完整 pieces、下一行动方 turn、winner 和可选 data。
}

function getLegalMoves(state, project) {
  // 返回所有合法走法，每个必须也能通过 onMove。
  return [{ from: { row: 2, col: 1 }, to: { row: 3, col: 1 } }];
  // 落子型：{ to: { row, col } }
  // 升变型：{ from, to, promotion: 'q' | 'r' | 'b' | 'n' }
}

function evaluate(state, side, project) {
  // 有限数值，越大表示对 side 越有利；推荐 -10000～10000。
  // 按游戏目标考虑胜利威胁、区域、资源等，不能一概用棋子数量。
  return 0;
}
```

`getLegalMoves` 和 `evaluate` 可以返回 Promise；调用应快速完成。所有与游戏有关的状态必须通过 `state` 传递，额外状态放在 `state.data`。同一局面同一动作必须产生相同的游戏结果，不依赖全局变量、时间或随机数；新建棋子的唯一 ID 除外。每个钩子获得独立输入副本，不能依赖跨调用修改。

胜负优先于 `evaluate`，评价分数会被限制在 ±100000。无评价函数时中间局面得分为 0，通过终局结果进行基础搜索。无合法走法、跳过回合和重复局面如何处理，需要规则在 `onMove` 返回的新状态中明确表达；搜索器不会擅自判负或和棋。

旧作品只有 `onMove` 时，会自动尝试棋盘落点以及已有棋子的起终点组合。不猜测自定义升变选择或其他动作语义；复杂棋类、升变和大棋盘应补充 `getLegalMoves`。预算内没有找到合法走法时会显示错误并暂停，可提高难度或完善规则后重试。

AI 助手已要求模型为新的自定义设计同时生成这两个接口。已有作品可点击建议「保持当前玩法，为人机对弈补齐 getLegalMoves 和 evaluate」，预览后应用。在规则编辑器中点击「测试电脑走子」可用当前草稿试运行一次搜索。

## 执行与校验

内置规则运行于打包的专用 Worker。自定义规则在无同源权限的 iframe 内创建 Worker，并通过 CSP 禁止网络访问；一次搜索在同一隔离环境内连续推演，结束、取消或超时后销毁。每个模拟结果会校验棋子、回合和状态；实际落子再次通过原规则引擎校验。

无限循环和异步不返回由页面上的超时保护终止。沙箱仍受浏览器整体内存限制，不是独立进程的内存配额。`getLegalMoves` 与 `onMove` 不一致、非法状态或非有限评分会暂停电脑并显示错误，用户可以返回编辑或改为双人操作。

## 验证

```sh
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
# 在另一个终端运行；需已安装 Playwright Chromium 或 Microsoft Edge。
node scripts/test-bot-browser.mjs
```

自动测试覆盖合法走法、必胜与防守、将死、升变、额外回合、旧规则适配、错误钩子、输入隔离、预算截止以及成组悔棋／重做。浏览器测试针对生产构建检查内置和自定义棋类、人机双方、自我对弈、暂停、撤销、重开、移动端设置与沙箱清理。
