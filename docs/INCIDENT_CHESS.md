# 异变象棋

本站作者 xuyinjie 原创。原实现来自作者指定的 `chess-room/packages/game-incident-chess`，规则的 JavaScript 版本保存在 `scripts/rules/incident-chess/`。运行 `npm run gallery:featured` 会拼接这些文件，将完整规则写入静态作品 JSON；运行时无需访问原 WSL 项目，不依赖服务端。下载、复制改编与编辑器试玩使用同一份规则。

## 作者确认的规则

- 沿用旧版：每次正常行动后由行动方三选一；瞬发立即处理，锦囊存储，持续技能长期生效。之后换方。不是标准象棋将军／自将保护规则。
- 广场同屏双人默认公开幻兵、幻马和虚子身份，作为规则沙盘。
- 允许修正明显程序错误。
- 火铳同时影响双方将帅时，先处理护甲与复活；最终双方都失去将帅则和棋。

## 操作

进入作品广场中的「异变象棋」，点击「开始试玩」再「开始对局」。红方先行。每次行动后点击带说明的技能卡；移动类技能选起点和终点，升级、放置、指定目标类技能直接点击高亮位置。瞬发可主动跳过，无效操作不消耗技能。

锦囊与持续技能分别显示在棋盘上下对应阵营的手牌区。点击锦囊选择目标；声东击西直接使用，金蝉脱壳标注被动触发。持续技能长期展示，有主动召唤能力的卡片可直接选择召唤位置。无合法目标时标注不可用原因。三选一在行动方的手牌区域显示。

锦囊与偃师召唤沿用原版的回合内附加操作，不代替正常走子。连续行动只能使用同一棋子，也可主动放弃第二动。被动复活优先于普通行动；金蝉脱壳优先于将魂犹在。全部 50 种技能说明可在技能图鉴展开查看。

棋子标记显示护甲、待劳、连动、良驹种类、原型剩余回合与幻子消失时机。棋谱分别记录移动、选技与技能使用，因此步数是操作数。悔棋、重做包含技能和随机序列，不会重新抽取已有选项。重新开始后使用新的随机序列。

## 迁移修正

- 技能池去除重复的骠骑将军，三选一不重复。
- 在执行引擎前校验完整合法操作，避免无效目标消耗瞬发。
- 将帅横竖一步允许吃子；将与马可以完成原技能规定的合体。
- 连动、护甲及棋子 ID 跟随合体后的棋子；破甲和炸毁不会遗留不可执行的第二动。
- 己方也可攻击装甲、地雷和虚子，与原技能文字说明一致；掩体不可被吃。
- 瞒天过海也处理护甲、地雷、晋升和将帅保命。
- 冲击、随行及火铳伤害尊重护甲；火铳可导致行动方失败或双方和棋。复活位置取将帅实际消失的位置，双方的待复活状态分别保存。
- 直角炮、士角炮以火铳为炮架的折线攻击也会引爆；借用走法与最高军阶合体不会误删不符合合体条件的己子。
- 原型到期后清除倒计时；没有新技能或没有复活空位时提供明确结束操作。

军阶走法、特殊炮的折线路径、傀儡范围和恐吓等其余技能沿用原实现。该规则组合众多，新增规则应同时补充交互用例。

## 文件与协议

`ability.js` 保存技能定义，`pieces.js` 保存走法，`engine.js` 处理效果，`state.js` 和 `core-*.js` 是迁移的基础模型及几何辅助函数。`adapter.js` 实现编辑器协议：`onMove`、`getLegalMoves`、`getGameView`、`evaluate`。状态以 JSON 保存在 `data.incident`，不保存重复棋盘；状态恢复时重新挂接引擎方法。

随机过程由开局生成的种子驱动，并随快照保存。人机为公开信息练习 AI，使用现有有界搜索和通用局面评价；未实现未知抽签分布的期望值搜索，不能视为专用强棋力 AI。由于广场选择公开沙盘，复制到编辑器后也不会恢复原版私密视角。

通用项目上限扩展为 64 种棋子、200,000 字符规则；单份项目依然受 500 KB 文件限制。规则界面增加可选的 `actions[].description`、`choices[].description`（最多 300 字），以及 `details`（最多 8 组，每组标题 60 字、正文 8,000 字）。全部按文本渲染并在沙箱边界校验。
